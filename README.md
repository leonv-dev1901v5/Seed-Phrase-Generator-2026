Generate crypto addresses (ETH, BSC and BTC) from random seed phrase and then check if transaction ever took place.

---
## ✨Features:

Randomly generate seed phrases using BIP39. (num_words=12/18/24 or your choice).
Then find corresponding ETH, BSC and BTC addresses using the seed.
Search the corresponding blockchains using API for any previous transaction histories.
If there is any transaction history, the script then save the seed phrase, address and blockcahin name in the 'data.json' file.
Library that have been used: pip install eth_account mnemonic bip32utils
